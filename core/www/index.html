隐私政策与用户协议

NasDSH 工作台 运行在您自有的 NAS 设备上，提供 DeepSeek Harness（dsh）的 Web 与 CLI 工作环境。

一、数据安全

  • 本应用没有开发者侧服务器；项目文件、会话与配置保存在您的 NAS 本地
  • 我们不上传、不收集、不分析您的代码、提示词或个人信息
  • 模型 API Key 由您自行配置，保存在本地数据目录

二、第三方服务

  • AI 能力由您配置的模型服务商提供，相关数据政策以服务商条款为准
  • 本应用随附 dsh（MIT）与 dsh-TUI（MIT）等开源组件，详见第三方声明

三、用户责任

  • 请妥善保管访问口令和 API Key
  • 请遵守所在国家/地区的法律法规，勿将本工具用于非法用途

点击「同意并使用」即表示您已阅读并同意上述条款。
